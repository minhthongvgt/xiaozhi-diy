## 🎯 CHI TIẾT CÁC LỖI

### 1️⃣ MEMORY LEAK TRONG TASK/QUEUE (CRITICAL)

#### **Lỗi 1.1: AudioService không cleanup Resampler**

```cpp
// ❌ LỖI: Trong SetDecodeSampleRate() - audio_service.cc dòng 725-735
void AudioService::SetDecodeSampleRate(int sample_rate, int frame_duration) {
    // ... 
    std::unique_lock<std::mutex> decoder_lock(decoder_mutex_);
    if (opus_decoder_ != nullptr) {
        esp_opus_dec_close(opus_decoder_);  // ✅ Đóng decoder
        opus_decoder_ = nullptr;
    }
    // ⚠️ NHƯNG: output_resampler_ NỀU TỒN TẠI TRƯỚC ĐÓ KHÔNG ĐƯỢC LẤY LOCK!
    // Nếu thread khác dùng nó → RACE CONDITION + MEMORY LEAK
    decoder_lock.unlock();
    
    // ... đặt lại decoder ...
    
    if (output_resampler_ != nullptr) {
        esp_ae_rate_cvt_close(output_resampler_);  // Close cũ
        output_resampler_ = nullptr;
    }
    // ... tạo resampler mới ...
}
```

**🐛 Vấn Đề:**
- **Race Condition**: Thread `OpusCodecTask` có thể đang dùng `output_resampler_` khi bạn close nó
- **Memory Leak**: Nếu `esp_ae_rate_cvt_open()` fail → `output_resampler_` = nullptr, nhưng decoder vẫn dùng nó → crash sau khi thay đổi sample rate

**✅ FIX:**

```cpp
void AudioService::SetDecodeSampleRate(int sample_rate, int frame_duration) {
    if (decoder_sample_rate_ == sample_rate && decoder_duration_ms_ == frame_duration) {
        return;
    }
    
    // LOCK TOÀN BỘ PROCESS
    std::unique_lock<std::mutex> decoder_lock(decoder_mutex_);
    
    // Close decoder
    if (opus_decoder_ != nullptr) {
        esp_opus_dec_close(opus_decoder_);
        opus_decoder_ = nullptr;
    }
    
    // ✅ TRƯỚC KHI CLOSE resampler, KIỂM TRA + LOCK
    esp_ae_rate_cvt_t old_resampler = output_resampler_;
    output_resampler_ = nullptr;
    
    decoder_lock.unlock();
    
    // Close OLD resampler NGOÀI lock (không block decode thread)
    if (old_resampler != nullptr) {
        esp_ae_rate_cvt_close(old_resampler);
    }
    
    // Tạo decoder mới
    esp_opus_dec_cfg_t opus_dec_cfg = OPUS_DEC_CFG(sample_rate, frame_duration);
    auto ret = esp_opus_dec_open(&opus_dec_cfg, sizeof(esp_opus_dec_cfg_t), &opus_decoder_);
    if (opus_decoder_ == nullptr) {
        ESP_LOGE(TAG, "Failed to create audio decoder, error code: %d", ret);
        return;
    }
    
    // ... đặt decoder_sample_rate_, decoder_frame_size_ ...
    
    // Tạo resampler mới (LẦN NÀY CÓ LỖI)
    if (decoder_sample_rate_ != codec->output_sample_rate()) {
        esp_ae_rate_cvt_cfg_t output_resampler_cfg =
            RATE_CVT_CFG(decoder_sample_rate_, codec->output_sample_rate(), ESP_AUDIO_MONO);
        auto resampler_ret = esp_ae_rate_cvt_open(&output_resampler_cfg, &output_resampler_);
        // ✅ KIỂM TRA LỖI TRƯỚC KHI DÙNG
        if (output_resampler_ == nullptr) {
            ESP_LOGE(TAG, "Failed to create output resampler, error code: %d", resampler_ret);
            // ⚠️ KHÔNG CRASH NẾU FAIL - BẠN PHẢI HANDLE CÓ OUTPUT RESAMPLER OR NOT
            // VD: Trong OpusCodecTask, check `if (output_resampler_ != nullptr)` trước dùng
        }
    }
}
```

#### **Lỗi 1.2: Queue Memory Leak - Deco Thread Hang**

```cpp
// ❌ LỖI: audio_service.cc dòng 600-650 (OpusCodecTask)
void AudioService::OpusCodecTask() {
    while (true) {
        std::unique_lock<std::mutex> lock(audio_queue_mutex_);
        audio_queue_cv_.wait(lock, [this]() {
            return service_stopped_.load() || !audio_encode_queue_.empty() ||
                (!audio_decode_queue_.empty() &&
                audio_playback_queue_.size() < MAX_PLAYBACK_TASKS_IN_QUEUE);
        });
        
        if (service_stopped_.load()) {
            break;
        }
        
        // Decode logic
        if (!audio_decode_queue_.empty() && 
            audio_playback_queue_.size() < MAX_PLAYBACK_TASKS_IN_QUEUE) {
            
            auto packet = std::move(audio_decode_queue_.front());
            audio_decode_queue_.pop_front();
            decode_in_flight_ = true;
            const uint32_t generation = playback_generation_;
            audio_queue_cv_.notify_all();
            lock.unlock();  // ✅ UNLOCK TRƯỚC
            
            // ... decode work (KHÔNG HOLD LOCK) ...
            
            lock.lock();  // ⚠️ LỖI: KHI NÀY, KIỂM TRA playback_generation_ 
            // ALE NẾU generation != playback_generation_ → TASK DROPOUT!
            // NỀU DROPOUT → decode_in_flight_ LẦN LUôN TRUE → DEADLOCK!
            if (decoded && generation == playback_generation_ && !service_stopped_.load()) {
                audio_playback_queue_.push_back(std::move(task));
            }
            decode_in_flight_ = false;  // ✅ NHƯNG ĐÂY CHỈ EXECUTE NẾU KHÔNG DROPOUT
            // → generate lỗi `decode_in_flight_` vĩnh viễn = true
        }
    }
}
```

**🐛 Vấn Đề:**
- Nếu `generation != playback_generation_` → task bị skip
- **NHƯNG** `decode_in_flight_` không được reset → **IsPlaybackDrainedLocked() LUÔN RETURN FALSE**
- **KẾT QUẢ**: `audio_queue_cv_.wait()` block vĩnh viễn → **DEADLOCK**

**✅ FIX:**

```cpp
void AudioService::OpusCodecTask() {
    while (true) {
        std::unique_lock<std::mutex> lock(audio_queue_mutex_);
        audio_queue_cv_.wait(lock, [this]() {
            return service_stopped_.load() || !audio_encode_queue_.empty() ||
                (!audio_decode_queue_.empty() &&
                audio_playback_queue_.size() < MAX_PLAYBACK_TASKS_IN_QUEUE);
        });
        
        if (service_stopped_.load()) {
            break;
        }
        
        if (!audio_decode_queue_.empty() && 
            audio_playback_queue_.size() < MAX_PLAYBACK_TASKS_IN_QUEUE) {
            
            auto packet = std::move(audio_decode_queue_.front());
            audio_decode_queue_.pop_front();
            decode_in_flight_ = true;
            const uint32_t generation = playback_generation_;
            audio_queue_cv_.notify_all();
            lock.unlock();
            
            // ... decode work ...
            
            lock.lock();
            // ✅ RESET decode_in_flight_ TRƯỚC KIỂM TRA generation
            decode_in_flight_ = false;
            
            if (decoded && generation == playback_generation_ && !service_stopped_.load()) {
                audio_playback_queue_.push_back(std::move(task));
            }
            
            const bool notify_drained = MarkPlaybackDrainedLocked();
            audio_queue_cv_.notify_all();
            lock.unlock();
            
            if (notify_drained && callbacks_.on_playback_drained) {
                callbacks_.on_playback_drained();
            }
            lock.lock();
        }
    }
}
```

#### **Lỗi 1.3: Task Stack Overflow - Input/Output Task 2KB không đủ**

```cpp
// ❌ LỖI: audio_service.cc dòng 100-125
void AudioService::Start() {
    // ...
    #if CONFIG_USE_AUDIO_PROCESSOR
    /* Start the audio input task */
    xTaskCreatePinnedToCore(
        [](void* arg) { ... },
        "audio_input", 2048 * 3,  // ✅ 6KB OK (có AFE + ESP_AE)
        this, 8, &audio_input_task_handle_, 0);
    
    /* Start the audio output task */
    xTaskCreate(
        [](void* arg) { ... },
        "audio_output", 2048 * 2,  // ⚠️ 4KB QUAY THIẾU!
        this, 4, &audio_output_task_handle_);
    #else
    // ...
    xTaskCreate(..., "audio_output", 2048, ...);  // ❌ 2KB CHỈ! 
    // ReadAudioData + codec->InputData() → CẬP NHẬT VECTOR → STACK OVERFLOW
    #endif
}
```

**🐛 Vấn Đề:**
- `audio_output_task_` gọi `codec->OutputData(task.pcm)` → SPI write → large stack usage
- **2KB STACK KHÔNG ĐỦ** → stack overflow sau vài lần playback

**✅ FIX:**

```cpp
/* Start the audio output task */
xTaskCreate(
    [](void* arg) { ... },
    "audio_output", 2048 * 4,  // ✅ Tăng lên 8KB để an toàn
    this, 4, &audio_output_task_handle_);
```

### 2️⃣ QUẢN LÝ FLASH/PSRAM LỖI (HIGH)

#### **Lỗi 2.1: AudioEngine không kiểm tra PSRAM availability**

```cpp
// ❌ LỖI: Trong AfeAudioEngine hoặc LiteAudioEngine initialization
// Không có check xem PSRAM có sẵn không trước khi allocate
// ví dụ: Wake word ring buffer alloc từ PSRAM mà PSRAM bị disabled
```

**🐛 Vấn Đề:**
- ESP32-S3-N16R8 có 8MB PSRAM, nhưng nếu menuconfig disable PSRAM → alloc fail âm thầm
- Ring buffer (64KB) được alloc từ PSRAM, nếu fail → WakeNet sẽ crash

**✅ FIX:**

```cpp
// Thêm vào audio_engine.h hoặc afe_audio_engine.cc
bool AudioEngine::CheckPsramAvailable() {
    uint32_t free_psram = esp_spiram_get_size();
    if (free_psram < 65536) {  // 64KB minimum for ring buffer
        ESP_LOGE(TAG, "PSRAM not available or insufficient (need 64KB, have %u bytes)", free_psram);
        return false;
    }
    return true;
}

// Gọi trong Initialize():
bool AfeAudioEngine::Initialize(...) {
    if (!CheckPsramAvailable()) {
        return false;  // FAIL SAFELY
    }
    // ... tiếp tục init ...
}
```

#### **Lỗi 2.2: NVS Commit không kiểm tra lỗi**

```cpp
// ❌ LỖI: settings.cc (không thấy, nhưng quy luật chung)
void Settings::SetInt(const char* key, int value) {
    nvs_set_i32(handle_, key, value);
    // ⚠️ KHÔNG CHECK RETURN VALUE!
    // esp_err_t ret = nvs_set_i32(...);
    // nvs_commit(handle_);  // ⚠️ KHÔNG COMMIT!
}
```

**🐛 Vấn Đề:**
- NVS writes được buffer → cần `nvs_commit()` mới flush đến flash
- Nếu không commit → data mất sau reboot

**✅ FIX:**

```cpp
// settings.h
class Settings {
public:
    void SetInt(const char* key, int value) {
        esp_err_t ret = nvs_set_i32(handle_, key, value);
        if (ret != ESP_OK) {
            ESP_LOGE(TAG, "nvs_set_i32 failed: %s", esp_err_to_name(ret));
            return;  // FAIL FAST
        }
        ret = nvs_commit(handle_);
        if (ret != ESP_OK) {
            ESP_LOGE(TAG, "nvs_commit failed: %s", esp_err_to_name(ret));
        }
    }
    // ... tương tự cho SetString, SetInt, v.v ...
};
```

### 3️⃣ XUNG ĐỘT I2S BCLK/WS (MEDIUM-HIGH)

#### **Lỗi 3.1: Pinout Configuration không xác thực**

```cpp
// ❌ LỖI: Không tìm thấy I2S config file chi tiết, nhưng dạo này là chỉ có:
// custom_s3_n16r8_board.cc chỉ có `// Board init test`
// 
// Nên mình giả sử I2S config ở audio_codec.cc hoặc board_init.h
```

**🐛 Vấn Đề Tiềm Ẩn:**

Trên **ESP32-S3**, I2S có **ràng buộc GPIO khắt khe**:

| I2S Port | BCLK | WS (LRCLK) | DIN | DOUT |
|---|---|---|---|---|
| **I2S0** | GPIO 5 | GPIO 25 | GPIO 26 | GPIO 35 |
| **I2S1** | GPIO 7/17 | GPIO 6/16 | GPIO 8 | GPIO 9 |

**Lỗi thường gặp:**
- Sử dụng **I2S0 BCLK=GPIO5, WS=GPIO25** → conflict với SPI MOSI (GPIO 23) nếu SPI cũng init
- **BCLK+WS cùng lúc** được clock từ I2S_CLK peripheral → nếu cấu hình sai → clock skew →
